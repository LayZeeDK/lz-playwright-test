# Mined UI shapes: hello-world (`hello-`) and the React demo app (`demo-`)

Sources:

- `hello-`: `Huluvu424242/stryker-playwright-hello-world` at `fa6dd64` (clone `D:/projects/github/Huluvu424242/stryker-playwright-hello-world`). UI is `index.html` only. `src/price.js` is plain logic with no markup, so it gives no UI shape. `docs/index.html` is not mined.

Design read: `docs/design/jsx-mutators.md` (operator list, Names, Equivalent mutants). `expect` is marked [checked] when a written design rule was applied to the snippet, [inferred] when the design is silent. A mutant's replacement text is shown after `->`. Emptied text uses `{null}` per the design's "Emptied text: `null`" [the exact printed form is inferred].

## No JSX equivalent

- `index.html:2` `<html lang="de">`: a document root. A component file has no `<html>`, and `lang` is on no operator list.
- `index.html:4-5` `<meta charset="UTF-8" />` and `<title>Stryker + Playwright Hello World</title>`: document head, outside any component. If the later HTML support reads `<title>`, it would be a `TextLiteral` shape, but the design does not name it.
- `index.html:20-27` `<script type="module">` with the inline import and the `onclick` assignment: script code, not markup. Only its handler shape is reused, in hello-9.

## Coverage and gaps

- Operators with a must-generate case: `TextLiteral` (hello-1, 2, 4, 6; demo-1, 2, 3, 5, 6), `LabelAttribute` (hello-3), `UrlAttribute` (demo-3, 4), `ElementRole` (hello-5, `ElementToSpan`), `ChildExpression` (demo-10, 11, 12, 13, 18).
- Operators with only must-not cases: `EventHandler` (hello-9, demo-8, 9), `ConditionalElement` (demo-14, 15).
- No shape in either source for: `DisabledAttribute`, `HiddenAttribute`, `StateAttribute`, `RoleRemoval`, a handler that is a non-inline reference, a JSX ternary or `&&` with a non-comparison test, and an `<a>` with or without `href` (the demo uses the router's `Link`, a component).
- Design points left unclear: (1) whether `ChildExpression` skips string-literal children such as `{' '}` and `.map` or `&&` expressions (demo-13, 14, 17); (2) whether a template-literal `aria-label` counts as a plain string for `LabelAttribute` (demo-7); (3) whether `UrlAttribute` applies to a component such as router `Link` (demo-3, 4), since the design lists the attribute names only; (4) the exact printed replacement for `TextRemoval` and for whitespace around emptied text (hello-6).
