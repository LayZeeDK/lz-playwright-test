# Mined UI shapes: analog

Repo `analogjs/analog` at `a377078ec`. The run used `apps/analog-app` (Angular SSR) with the Playwright suite in `apps/analog-app-e2e/tests/` (`oss/README.md` section "analog"; mutated file was `(home).page.ts`). Every origin below was read with `git show a377078ec:<path>`. Paths are relative to the clone root. The app is Angular, so every origin is an Angular template and every `jsx` cell is its JSX equivalent (rules from the brief: `routerLink`/`linkTo` becomes `href` on an `a`, `(click)` becomes `onClick`, `for` becomes `htmlFor`, `@if` becomes `&&` or a ternary).

Notation: in `expect`, `Op/Mutation: text` is the replacement for the part named. "own ElementToSpan" means the tag becomes `span` and the other attributes stay (design is silent on whether they stay, [inferred]). Each expect carries [checked] (design rule applied to the snippet) or [inferred] (design silent, judged).

## No JSX equivalent

- `libs/top-bar/src/lib/top-bar/template.html:16` and `:20`: `routerLink="/"`, `routerLink="/cart"`. Mapped to `href` as the brief says (analog-1, analog-2), so these are covered.
- `apps/analog-app/src/app/pages/products.[productId].page.ts:20` `<h4>{{ product.price | currency }}</h4>` and `apps/analog-app/src/app/pages/server-functions.page.ts:40` `{{ product | json }}`: Angular pipes. A call such as `{currency(product.price)}` would be a plain `ChildExpression` case, but that is a different shape. This `h4` is what `products.spec.ts:44` asserts through `fixtures/product-details.po.ts:18`, so the Angular-template version is a good later case.
- `apps/analog-app/src/app/pages/shipping/shipping.html:2` `@for (shipping of shippingCosts | async; track $index)`: `async` pipe, no JSX form.
- `apps/analog-app/src/app/pages/cart.page.ts:25`, `:28` `[formGroup]`, `formControlName`; `apps/analog-app/src/app/pages/newsletter.page.ts:27-30` `[enhanceForm]`, `(onSuccess)="onSuccess($any($event))"`, `(state)="$event === 'submitting' && errors.set(undefined)"`: Angular form and output bindings with no JSX attribute equivalent. The `(state)` handler is an expression, closest to an inline arrow, so a skip.
- `apps/analog-app/src/app/pages/(home).page.ts:16`, `libs/shared/feature/src/pages/about-you.page.analog:1` (`<template>Hello You</template>`): component and SFC wrappers, not UI markup the operators target.

## Operators this UI does not show

`DisabledAttribute`, `HiddenAttribute`, `StateAttribute`, and `ElementRole` `RoleRemoval` have no shape in `apps/analog-app`, `libs/top-bar` or `libs/shared` (searched for `aria-`, `role=`, `disabled`, `hidden`, `readonly`, `placeholder`). `placeholder` and `alt` appear only as `alt` in `Configure.mdx`.

## What the design leaves unclear

1. `ChildExpression` on a call, optional chain, `.map(...)` or `x && <A/>` child: "a `{value}` child" does not say which expression kinds qualify, and a `{cond && <A/>}` child would overlap `ConditionalElement` (analogs 4, 10, 19, 20).
2. `UrlAttribute` on a non-literal `href={...}` (analog-3): `LabelAttribute` says "plain-string", `UrlAttribute` does not.
3. `ElementToSpan`: whether `href`, `type`, `onClick` stay on the `span` (the cases keep them).
4. `EventHandler` on a component's `onX` prop and on an Angular output with no `on` prefix (analog-7).
5. `LabelAttribute` on `htmlFor` that already points at no element (analog-14) is equivalent and has no skip.
